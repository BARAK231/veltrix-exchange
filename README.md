# VELTRIX EXCHANGE

VELTRIX EXCHANGE is a cryptocurrency exchange platform foundation.

Symbol: VLX

## Current status

- Account system
- Secure password hashing
- Session authentication
- PostgreSQL database foundation
- Asset balances
- Ledger
- Telegram mining credit API
- Audit logs
- Order database foundation
- VLX planned listing configuration

## Important

Telegram mining credits are internal exchange ledger credits until real blockchain infrastructure is deployed.

VLX listing date is currently configured as a plan:

17 November 2026

This date is not a confirmation of an actual exchange listing.

npm install
